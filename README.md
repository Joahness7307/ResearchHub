# ResearchHub

ResearchHub is a web-based Platform for Managing and Archiving Research Manuscripts for Consolatrix College of Toledo City, Inc.

## Project Description

The system allows students to submit research proposals, teachers to review and provide feedback, and administrators to manage and publish approved research projects.

## Features

- Student Research Proposal Submission
- Teacher Proposal Review and Feedback
- Admin Approval and Research Repository
- Role-Based Access Control (Student, Teacher, Admin, Guest)
- Secure Authentication System

## System Users

1. Students
2. Teachers (Reviewers)
3. Administrators
4. Guest

## Installation Guide

### 1. Clone the Repository

git clone https://github.com/Joahness7307/ResearchHub.git

### 2. Install Backend Dependencies

cd backend
npm install

### 3. Install Frontend Dependencies

cd frontend
npm install

### 4. Run the Backend

npm start
or
node server.js

### 5. Run the Frontend

npm start
